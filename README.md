# Reloj Digital ⏰

Un proyecto sencillo de un reloj digital creado con HTML, CSS y JavaScript puro. Muestra la hora actual en formato de 12 horas (HH:MM:SS) junto con el indicador AM/PM, y se actualiza en tiempo real cada segundo.

## Características

- **Hora en tiempo real:** El reloj se actualiza cada segundo sin necesidad de recargar la página.
- **Formato de 12 horas:** Muestra la hora en un formato amigable con indicador AM/PM.
- **Diseño moderno:** Interfaz limpia y minimalista con un efecto de brillo de neón verde.
- **Ligero y rápido:** Construido con tecnologías web básicas, sin dependencias de frameworks.

## Tecnologías Utilizadas

- **HTML5:** Para la estructura básica del reloj.
- **CSS3:** Para el diseño, el centrado y los efectos visuales como el color y la sombra.
- **JavaScript (ES6+):** Para la lógica de actualización de la hora en tiempo real.

## Cómo usarlo

1.  Clona o descarga este repositorio en tu máquina local.
2.  Abre el archivo `index.html` en tu navegador web favorito.
3.  ¡Y eso es todo! El reloj comenzará a funcionar inmediatamente.
